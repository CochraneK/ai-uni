# 004 · Future Me

## Goal

Create a compelling conversation with a **possible future self** from the participant's own information.

## Current flow

1. participant enters current self / important experiences / values & goals
2. chooses a future distance
3. model generates a structured future persona
4. optional future portrait generation
5. participant chats with that future persona
6. browser TTS can read the latest future-self response
7. all user-authored material remains available to the shared report layer

## Product boundary

This is not a life simulator and does not claim to predict the participant's actual future.

## Shared dependencies

- participant identity
- provider settings
- conversation storage
- report / analysis layer
- future secure admin backend
