# 005 · Character Studio

## Goal

Let participants **create**, not choose, an original AI character, give it an image, and talk with it.

## Current flow

1. participant writes a one-sentence character idea
2. optionally describes relationship, tone and a hidden story
3. model completes a structured persona
4. image model creates an original character portrait
5. participant chats with the character
6. character conversation is preserved

## Design rule

Examples are inspiration only. The main path must never force the participant into a pre-authored role catalog.

## Analysis boundary

Created-character fiction can be analyzed as preference/projective material only with strong caveats. It must never be silently reclassified as the participant's autobiographical fact or psychiatric symptom.
